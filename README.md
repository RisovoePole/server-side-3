## Отчёт по лабораторной работе №3

Я разработал веб-приложение «Система управления учебными курсами» на Express.js и EJS с архитектурой MVC. Все маршруты вынесены в `routes/courseRoutes.js`, обработка запросов — в `controllers/courseController.js`, данные и операции с ними — в `models/courseModel.js`. В модели хранится массив из шести курсов (по условию работы база данных не подключается, поэтому после перезапуска сервера изменения теряются).

### Что работает

- просмотр списка курсов и отдельной страницы курса;
- добавление, редактирование и удаление курсов (ID присваивается автоматически, удаление требует подтверждения через `confirm`);
- поиск по названию и преподавателю без учёта регистра, фильтр по семестру и совместное применение поиска и фильтра;
- валидация формы через `middleware/validateCourse.js`: при ошибке курс не изменяется, показывается список понятных сообщений, а введённые пользователем значения остаются в полях;
- логирование каждого запроса в терминал в формате `GET | /courses | 22.11.2026 23:56` (`middleware/logger.js` подключён до маршрутов);
- страницы 404 (неизвестный маршрут или несуществующий курс) и общей ошибки 500 без вывода stack trace;
- EJS-шаблоны с partials `header.ejs` и `footer.ejs`, оформление в `public/css/style.css` (кнопки просмотра, редактирования и удаления различаются цветом).

### Структура проекта

```
app.js                         — настройка Express, middleware и обработка ошибок
package.json                   — зависимости и команда запуска
routes/courseRoutes.js         — маршруты
controllers/courseController.js — обработчики запросов
models/courseModel.js          — массив курсов и операции с ним
middleware/logger.js           — логирование запросов
middleware/validateCourse.js   — проверка данных формы
views/courses/                 — index, details, create, edit
views/partials/                — header, footer
views/404.ejs, views/error.ejs — страницы ошибок
public/css/style.css           — стили
```

### Как запустить

```bash
npm install
npm start
```

После этого приложение доступно по адресу **http://localhost:3000** (порт по умолчанию — 3000). Если на машине порт 3000 уже занят другим приложением, можно запустить, например, `PORT=3001 npm start` и открыть `http://localhost:3001`.
